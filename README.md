# 🏆 Álbum Copa 2026 - DASPORTS

Este é um projeto de e-commerce moderno para colecionadores de álbuns e figurinhas da Copa do Mundo 2026. O site conta com uma interface premium, responsividade completa e um sistema de banco de dados interno para gerenciamento de usuários e pedidos.

## ✨ Funcionalidades

- **🛒 E-commerce Completo:** Navegação por categorias, detalhes de produtos e carrinho funcional.
- **🔐 Autenticação Interna:** Sistema de login e cadastro persistente utilizando `LocalStorage`.
- **📱 Responsividade Total:** Design otimizado para celulares, tablets e desktops com menu mobile.
- **📦 Gestão de Pedidos:** Checkout funcional que gera e armazena números de pedidos.
- **⚡ Performance:** Desenvolvido com React + Vite para carregamento instantâneo.

## 🛠️ Tecnologias Utilizadas

- **React 19**
- **Vite**
- **Lucide Icons**
- **Vanilla CSS** (Design Customizado)
- **Local Persistence Engine** (Banco de dados simulado)

## 🚀 Como Executar o Projeto

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Abra o navegador em `http://localhost:5173`

## 📂 Estrutura de Pastas

- `src/components`: Componentes reutilizáveis (Header, Hero, etc).
- `src/pages`: Páginas da aplicação (Home, Login, Cart, Checkout).
- `src/context`: Gerenciamento de estado global (Auth e Cart).
- `src/lib`: Motor de banco de dados e serviços.
